# Exporting

[← Help home](README.md)

Click the big **Export** button (top right), or **File → Export…** (`Ctrl+E`).

## Presets

Pick one and everything else is filled in for you:

- **Same as the project**: your project's size and frame rate.
- **YouTube 1080p** and **YouTube 4K**.
- **Shorts / TikTok / Reels (tall)**: 1080×1920. If your project is wide, set its shape to tall first (see [Settings](settings.md)) and use *Fill the frame* on your clips, or you'll get black bars.
- **Instagram square**.
- **Small file to send**: 720p, smaller file.
- **GIF**: a moving picture with no sound, for chats and docs.
- **Sound only**: MP3 (or M4A).

Change any setting by hand and it switches to *Custom*. It remembers what you used last time.

## Instant vs normal

- **Instant** copies the video as it is, without redoing it, so it takes seconds. Only works for simple cuts from one video with no titles, effects or other changes.
- **Normal** rebuilds every frame. Needed for everything else.

**Use the graphics card** makes normal exports much faster. If your graphics card can't do it, MixMedia quietly uses the CPU instead.

## Subtitles

If your project has subtitles, choose whether they go in the picture, in an `.srt` file next to the video, and/or as a track viewers can switch on. See [Subtitles](subtitles.md).

## Where it goes

Pick the file name and folder at the top. When it's done, **Show in folder** takes you straight to it.
