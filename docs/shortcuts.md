# Keyboard shortcuts

[← Help home](README.md)

## Playing

| Key | What it does |
|---|---|
| Space | Play / pause |
| ← / → | Back / forward one frame |
| Shift+← / Shift+→ | Back / forward one second |
| ↑ / ↓ | Previous / next cut |
| Home / End | Go to the start / end |

## Editing

| Key | What it does |
|---|---|
| S (or Ctrl+B) | Split at the playhead |
| Delete | Delete, closing the gap |
| Shift+Delete | Delete, leaving a gap |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste (at the playhead) |
| Ctrl+A | Select everything |
| Ctrl+click | Add a clip to the selection |
| Ctrl+D | Detach audio |
| Ctrl+T | Add a title |
| Ctrl+Shift+F | Freeze frame |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z or Ctrl+Y | Redo |

## The timeline

| Key | What it does |
|---|---|
| Ctrl+= / Ctrl+- | Zoom in / out |
| Ctrl+0 | Fit everything |
| Ctrl + mouse wheel | Zoom around the mouse |

## Files

| Key | What it does |
|---|---|
| Ctrl+N | New project |
| Ctrl+O | Open a project |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+I | Import media |
| Ctrl+E | Export |
| F1 | This help |

## The window

| Key | What it does |
|---|---|
| F11 | Full screen (F11 again to leave) |
